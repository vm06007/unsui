# unsui
UnSui is transit card to crypto wallet solution. An NFC-powered prototype for Japanese transit-card refunds, with multichain payouts, World ID verification, and a dashboard connecting merchant payments to cryptographic receipts.

## Project structure

- `mobile/` — React Native foundation for Android and iOS.

See [mobile/README.md](mobile/README.md) for setup. NFC scanning, refunds,
contracts, backend, web and dashboards are planned next.
